# Source and freshness

Every file in this repository except `LICENSE` is generated by an automated job from outputs
that are already public on the LTCMA research site: the pages at <https://duiarte.github.io/ltcma/> and the
published data files in <https://github.com/DuiArte/ltcma>. The job reads nothing private, and nothing here
is edited by hand; a correction is made at the source and reaches this repository on the
next run.

checked with `git cat-file -p <id>` in a clone of https://github.com/DuiArte/ltcma.

## How this repository stays current

- The job regenerates every file from the outputs above and compares the result with what
  is committed here.
- It commits only when a published figure or statement changes. A site rebuild that leaves
  every figure here unchanged produces no commit, so the date of the last commit is the date
  the published content last changed, not the date the job last ran. The *As of* dates
  above can therefore be older than the site's latest rebuild.
- Every candidate change passes a fail-closed leak scan before it is committed; a hit stops
  the sync for this repository.
